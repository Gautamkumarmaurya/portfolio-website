# Gautam Kumar — Premium Full Stack Developer Portfolio

Production-style portfolio built with React, Vite, Tailwind CSS and Framer Motion.

## Features
- Premium dark UI with purple/cyan/lime visual system
- Fully responsive desktop/tablet/mobile layouts
- Sticky glass navigation
- Motion-ready section reveals and hover interactions
- Recruiter-focused hero, skills, projects, experience and GitHub sections
- Direct GitHub, LinkedIn and resume links
- Uses Gautam's provided Cloudinary profile image
- Accessible semantic sections and external links

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Contact form

Submitting the contact form opens the device's default email app with a prefilled message addressed to `gautamsingh802215@gmail.com`. The sender can review the recipient, subject, and message, then send it from that app. A mail app must be configured on the device; sending email without signing into an email account is not possible.

## Production build

```bash
npm run build
npm run preview
```

## Deploy

### Vercel
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.

### Netlify
Build command: `npm run build`
Publish directory: `dist`
